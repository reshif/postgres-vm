# ADR-0016: Poll ingestion is the backstop, webhooks are the optimisation

## Context

Plane A only has value if it is current. A webhook gives low latency but fails
open: a missed delivery, a retry into a 500, or a push while the API is
restarting leaves the platform permanently stale with nothing indicating it.

## Decision

Run both. The scheduler reconciles the `.memory/` tree on an interval and is the
correctness guarantee; `POST /v1/ingest` exists so a merged decision is
retrievable in seconds rather than at the next poll. Ingestion is idempotent, so
both firing for the same commit is harmless.

Reconciliation lives in the scheduler rather than the worker queue because it is
not event-driven work, and two workers reconciling the same tree would race on
the supersede path.
